لعبة "التخمين بالإيموجي" — نسخة كاملة قابلة للعب (تصميم Neumorphism)
=====================================================================

طريقة التشغيل:
- افتح ملف index.html مباشرة في أي متصفح على الجوال أو الكمبيوتر (بدون
  الحاجة لأي سيرفر أو تثبيت). يفضّل استخدام المتصفح على جهاز جوال
  لأن التصميم مبني أساسًا لذلك (Mobile First).

هيكل الملفات:
- index.html          → كل شاشات اللعبة (12 شاشة حسب تدفق المواصفات)
- css/style.css        → تصميم Neumorphism كامل + كل الأنيميشنز المطلوبة
- js/data.js           → بنك الأسئلة (50 دولة + 50 أكلة)
- js/state.js          → الحالة المركزية للعبة + الإعدادات القابلة للتعديل
- js/playerSetup.js    → إدخال الحكم واللاعبين
- js/teamAssignment.js → توزيع الفرق عشوائيًا (زوجي/فردي + لاعب مشترك)
- js/questionManager.js→ سحب الأسئلة ومنع التكرار
- js/timerManager.js   → المؤقت العام (5 دقائق / دقيقة / 15 ثانية)
- js/scoring.js        → حساب النقاط والفوز
- js/assists.js        → مساعدتا المضاعفة والبحث
- js/dice.js           → مساعدة النرد
- js/categorySwitch.js → اختيار/تبديل المجال
- js/roundManager.js   → منسّق تدفق اللعبة الكامل (الملف الأهم لفهم المنطق)
- js/victory.js        → تأثير الاحتفال بالفوز
- js/uiRender.js       → كل التعامل مع الواجهة (DOM)
- js/main.js           → ربط الأزرار بالأحداث عند بدء التشغيل

مكان الشعار:
- في أعلى شاشة البداية، يوجد صندوق بعنوان "🖼️ مكان الشعار (Logo)".
  استبدله بشعارك الخاص عبر تعديل ذلك العنصر في index.html (يمكن وضع
  <img src="..."> بدلًا من النص).

قرارات تم توضيحها في الكود لأن المواصفات لم تحددها صراحة (كما طلبتَ،
كل واحدة موضوعة في مكان واضح وقابل للتعديل بدل أن تكون منطقًا مخفيًا):
1. عدد الجولات في الدورة الواحدة قبل ظهور النرد واختيار المجال = 2
   (Game.CONFIG.ROUNDS_PER_CYCLE في js/state.js).
2. الفريق "البادئ" لكل جولة يتناوب: الجولة الأولى الفريق الأول، ثم
   الفريق الثاني، وهكذا — ونقاط الجولة (2 للبادئ / 1 للفريق الثاني إن
   انتقل له السؤال) تتبع "الدور" وليس رقم الفريق الثابت.
3. بعد انتهاء وقت مساعدة البحث (15 ثانية)، يتوقف المؤقت الرئيسي ولا
   يُستأنف تلقائيًا؛ يقرر الحكم يدويًا (صح/خطأ) مباشرة بعد ذلك.

كل الأسئلة والقواعد مطابقة لملفات الأسئلة والمواصفات التي أرسلتها، مع
تصحيح بسيط لبعض الرموز غير الإيموجي (مثل نص "Tango" أو أعلام خاطئة)
حتى تعمل اللعبة بالإيموجي فقط كما هو مطلوب.
